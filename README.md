# lay2web

A minimal layout mockup board for web designers. Think Excalidraw meets a stripped-down Figma:
no real images, no fonts — just black image placeholders and plain text blocks on a page-width canvas.

**Live:** https://eduard256.github.io/lay2web/

## Features

- Desktop (1440px) and Mobile (390px) canvases, unlimited height
- Image placeholder blocks with aspect ratio lock and quick ratio presets
- Text blocks with a single fixed font (size, alignment, bold)
- Select, multi-select, marquee, drag, resize, snapping guides
- Copy / paste / duplicate, undo / redo, lock blocks in place
- 15 preset layouts (hero, grids, masonry, cards, stories, …)
- One-click auto layout into a column grid
- Save / load JSON, export static HTML or PNG
- Autosave to localStorage

## Shortcuts

| Key | Action |
| --- | --- |
| `I` / `T` | Add image / text block |
| `P` | Presets panel |
| `A` | Auto layout |
| `Ctrl+D` | Duplicate |
| `Ctrl+C` / `Ctrl+V` | Copy / paste |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Undo / redo |
| `Del` | Delete |
| `L` | Lock / unlock |
| Arrows (`Shift` ×10) | Nudge |
| `Ctrl` + wheel, `Ctrl+0` | Zoom, fit |
| `Space` + drag | Pan |

## Run locally

Open `index.html` in a browser — no build step, no dependencies.
